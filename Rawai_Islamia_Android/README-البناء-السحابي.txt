روائع إسلامية — البناء السحابي لإخراج APK

هذه النسخة مجهزة للبناء بدون Android Studio على جهاز المستخدم.

طريقة الاستخدام:
1) ارفع محتويات هذا المشروع إلى مستودع GitHub جديد.
2) ادخل إلى تبويب Actions.
3) اختر: Build APK - روائع إسلامية.
4) اضغط Run workflow.
5) بعد نجاح البناء افتح نتيجة التشغيل وانزل إلى Artifacts.
6) نزّل Rawai-Islamia-debug-apk.zip.
7) فك الضغط وستجد app-debug.apk جاهزًا للتثبيت على Android.

البناء يتم على خوادم GitHub Actions، وليس على جهاز المستخدم.
الـAPK الناتج Debug APK قابل للتثبيت للاختبار. للنشر الرسمي على Google Play نحتاج لاحقًا إلى إنشاء مفتاح توقيع Release محفوظ كـGitHub Secret.
